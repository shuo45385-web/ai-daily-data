# ai-daily-data

每日开源 AI 精选的数据仓库。每天由 AI 阅读 GitHub 项目文档后人工筛选 10 个真正值得关注的开源 AI 项目，写入 `data/yyyy-MM-dd.json`，个人系统从这里同步。

每个文件保留既有的 `date`、`title`、`projects` 和 `sources` 字段；项目包含排序、分类、简介、部署方式、许可证和链接，并额外补充 GitHub 星标、语言、主题及更新时间等元数据。

筛选会优先考虑项目的实际可用性、近期活跃度、开源与部署条件，以及对开发者的价值；不会只按标签或星标机械抓取。同日期文件默认不重复写入，发现信息需要修正时才会更新。
